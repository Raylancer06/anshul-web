## 🚀 Deployment Options

### 1. GitHub Pages (Automated)
The included `.github/workflows/deploy.yml` automatically publishes the site whenever changes are pushed to `main`.

### 2. Vercel
Deploy in seconds:
```bash
npx vercel --prod
```

### 3. Netlify
Deploy via Netlify CLI:
```bash
npx netlify deploy --prod
```
